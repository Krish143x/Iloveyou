A HEART MADE OF LANGUAGES — QUICK START
=========================================

FILES
- index.html: the complete romantic animated heart project. No installation or internet connection is required to open it.
- README.txt: these instructions.

HOW TO CHECK IT ON YOUR MAC
1. Download and unzip language_heart_project.zip.
2. Open the extracted folder named language_heart_project.
3. Double-click index.html. It should open in your default browser (Safari, Chrome, etc.).
4. Check that the red phrases form a heart, move gently, and that the center message is visible.
5. Scroll down and click “Replay the heart” to test the animation.
6. Make the browser window narrow or open the file on a phone-sized window to check that it adapts.
7. Confirm the final two phrases are Hindi (“मैं तुमसे प्यार करता/करती हूँ”) and Nepali (“म तिमीलाई माया गर्छु”).
8. If the file looks odd, right-click index.html and choose Open With > Google Chrome or Safari. You can also drag index.html into an open browser window.

HOW TO PERSONALIZE IT
- To change the heading, open index.html in VS Code or another text editor.
- Find: A Heart Made of Languages ❤️
- Replace only the words between the title/header tags if desired.
- To change the message in the middle, search for “Across every language”.
- Save the file, then refresh the browser tab to see changes.
- Keep the final two entries in the phrases list as Hindi followed by Nepali if you want to preserve your requested order.

HOW TO SEND IT SO IT IS EASY FOR HER TO OPEN
Option A — easiest to share as a file:
1. Send language_heart_project.zip through WhatsApp, email, Google Drive, or another file-sharing app.
2. Tell her to download the ZIP and extract/unzip it.
3. She should open the extracted folder and tap/double-click index.html. On a phone, she may need to use the Files app to extract the ZIP, then choose a browser to open index.html.
4. Some messaging apps do not preview HTML files. Downloading and opening the file in a browser is normal.

Option B — easiest to access with one tap:
1. Publish the index.html file as a static website using a hosting service such as GitHub Pages or Netlify.
2. Share the resulting website link with her. She can open it in Safari/Chrome without downloading the project.
3. Before publishing, review the page and remove anything private. Never include passwords, private photos, or personal contact details in a public project.
Note: hosting websites may change their setup steps, and some require an account.
